1. Introduction
AX-Synth Librarian is an application that lets you use your computer to manage AX-Synth tone settings as "libraries."
This allows you to manage numerous Tones efficiently with your computer.
"SuperNATURALTM" and "Special" Tones cannot be handled by AX-Synth Librarian.
When using AX-Synth Librarian, select a “regular” tone on the AX-Synth beforehand.
The "Tones" of the AX-Synth are equivalent to the "Patches" in the AX-Synth Librarian.
The AX-Synth features a sound generating engine that is derived from the Fantom-X (However, it is not multitimbral).
This means that the parameters handled by this librarian are a subset of those on the Fantom-X.
When using AX-Synth Librarian, substitute the terms as shown below.

2. Connections and Settings
Connect the AX-Synth and your computer as described in AX-Synth owner’s manual.
AX-Synth Librarian may not operate correctly if these connections are not made correctly.
If the AX-Synth is connected to your computer by a USB cable, you must power up the AX-Synth before you start up 
AX-Synth Librarian.
Do not disconnect the USB cable connected to the AX-Synth while AX-Synth Librarian is running.

nect both the MIDI IN and MIDI OUT connectors on the MIDI interface connected to your computer to the MIDI con-

When using the software for the first time, you must choose the menu command [SETUP] - ”Set Up MIDI Devices” to

3. Overview of AX‐Synth Librarian
This is a graphic display window. 
The window displays Patches in the AX-Synth as lists, and it includes categories where you can edit names, add 
comments, and change the order in which information appears according to keywords.
The Main Window is the primary window used when data is being exchanged with the AX-Synth. 
It corresponds to the AX-Synth’s Patch Area (Patch Memory).
The AX-Synth can store up to 256 patches.
All of these patches are organized according to Bank (1-8) and Number (1-32).
For example, a patch saved to "1-2" of the AX-Synth Librarian will be stored in the second location of the AX-Synth's 
Bank 1.
This is a graphic display window. 
Just as with the Main Window, Patches are displayed as lists, and you can edit names and change the order in which 
the information appears.
You can have multiple Library Windows open at the same time.
You can copy and paste the data in one Library Window to and from the Main Window and other Library Windows.
Data you intend to use for a particular purpose can be collected and arranged in one window. The data you include 
there might belong to a certain musical genre, or might have been created by a certain artist.
Afterwards, simply by saving the content of the window in a file, you can create your own library.

INIT data (data having standard values) in the same

scratch.

5. Using AX‐Synth Librarian
Load Patches into AX-Synth Librarian from the AX-Synth’s Patch Area.
•  When you run [ MIDI] - “ Read All Data ” or click the [ Read All] button in the upper part of the Main Window, all
Patches in the AX-Synth’s Patch Area are read into the Main Window.
•  You can use the “Read Selected Data” command or the [Read Selected] button to have only the selected data be
read from the AX-Synth’s Patch Area.
Whether you are in the Main Window or the Library Window, you can rename or sort the entries in the patch list.
You can also save the content of Library Windows as files.
Using the Mouse for Editing Data
If you select a range of rows and then right-click, you can simultaneously input the same character string in all of the 
selected rows.
To confirm the input, either press the Enter key or click somewhere on the screen other than the input box.
Right-click or press the Esc key to cancel the input.
Keyboard Functions When Editing Data
You can input using only the keyboard by using the following keys.
Audition button
When you click the button at the left end of each row (Audition button) in the Patch list, you can have the corre-
sponding data be sent to the AX-Synth’s Temporary Area, allowing you to audition the sound in the AX-Synth.
You can achieve the same result by double-clicking in the row.

6. Notes Concerning Use of AX‐Synth Editor Together with AX‐Synth Librarian
Patch Name
Provides of entry of the Patch names.
Patch names of up to twelve characters can be entered.
You can use the following characters,
space ! “ # $ % & ‘ ( ) * + , - . / 0-9 : ; < = > ? @ A-Z [ \ ] ^ _ ` a-z { | } ~
Memo 1--4
This allows you to enter up to four comments of your choice. 
Here you may want to include information such as the data’s creator and date it was created.
This information is not saved to the AX-Synth itself.
Arrange Data
When you click on the boxes in the top row of the display (Number, Patch Name, Memo 1--4), the data is listed in the 
sequence corresponding to the clicked box.
Write the Patches in the Main Window to the AX-Synth’s Patch Area.
•   When you issue the command [MIDI] - “Write All Data” or click the [Write All] button in the upper part of the Main
Window, all Patches in the Main Window are written to the AX-Synth’s Patch Area.
•  By using “ Write Selected Data ” or the [ Write Selected] button, you can write just the selected data to the AX-
Synth’s Patch Area.
If the AX-Synth is connected to your computer using a USB cable, you may not be able to use AX-Synth Editor 
together with AX-Synth Librarian. In such cases, try installing the Roland original driver.
For details, refer to the AX-Synth owner's manual.
You may experience some of the problems below if AX-Synth Librarian and AX-Synth Editor are used at the same 
time.
•   When you click the Audition button in AX-Synth Librarian, the correspondence between the values in AX-Synth
Editor and the data in the AX-Synth’s Temporary Area may be lost.
•  After you’ve issued the “Write All Data” or “Write Selected Data” commands in AX-Synth Librarian, the names of
items and their sequence in AX-Synth Editor may no longer match the data in the AX-Synth’s Patch Area.
If you have performed one of the above operations in AX-Synth Librarian and then move to AX-Synth Editor, you 
must be sure to click the [SYNC] button located in the top line of AX-Synth Editor’s Main Window before you begin 
editing. This executes the following actions, allowing the AX-Synth Editor and AX-Synth settings to be synchronized.
•  The values of settings in AX-Synth Editor are written to the AX-Synth’s Temporary Area.
•  The name lists of Patch in the AX-Synth’s Patch Area are read into AX-Synth Editor.

7. If the Display Indicates “Unable to read/write data.”
In cases such as following, the display may indicate “Unable to read/write data.”
•   When the AX-Synth and the computer are not connected properly
•   When a large number of notes are being sounded
•   When AX-Synth Editor and AX-Synth Librarian simultaneously attempt to read (or write) data
•   When the driver you’re using is the generic MIDI driver included with the OS, and you’ve attempted to use both AX-
Synth Editor and AX-Synth Librarian at the same time.
